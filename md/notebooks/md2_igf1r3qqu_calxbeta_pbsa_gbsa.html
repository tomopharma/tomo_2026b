IGF1R / calx-β — MM-GBSA binding free energy (post-MD)¶

Follow-up to md1_igf1r3qqu_calxbeta_gromacs.ipynb. If any frames have ΔG ≥ 0, continue with md3_igf1r3qqu_calxbeta_binding_inspection.ipynb.

Reads saved production MD artifacts from data/md_calx_3qqu/ (via md_results_manifest.json) and estimates:

$$\Delta G_{\mathrm{bind}} \approx \langle G_{\mathrm{complex}} \rangle - \langle G_{\mathrm{receptor}} \rangle - \langle G_{\mathrm{ligand}} \rangle$$

using MM-GBSA (Generalized Born implicit solvent) through gmx_MMPBSA — the standard tool for GROMACS + AMBER force field trajectories (amber99sb-ildn in our pipeline). PBSA is available via config (MMPBSA_METHOD = "pbsa").

Pipeline (conceptual)¶

  1. Load MD inputs — production md.tpr, trajectory, and topology from the GROMACS notebook.
  2. Frame selection — keep Protein only (receptor + calx-β); water is unused because MM-GBSA/PBSA use implicit solvent. Optionally stride frames (TRJCONV_DT_PS) so the average is over a manageable set of snapshots.
  3. Receptor vs ligand — index groups: receptor = all protein chains except B; ligand = chain B (calx-β).
  4. MM-GBSA / MM-PBSA — per-frame free-energy estimate with gmx_MMPBSA (GB by default; PB optional).
  5. Report ΔG_bind — mean across frames ± uncertainty (SEM and bootstrap 95% CI).

Production length is inferred from the trajectory (gmx check last-frame time) and, when present, cross-checked against md.mdp (nsteps × dt) — not hardcoded.

Dependencies: dedicated conda env gmxMMPBSA (AmberTools + gmx_MMPBSA; not installed into the Jupyter kernel).

mamba create -n gmxMMPBSA python=3.11 -y
mamba install -n gmxMMPBSA -c conda-forge ambertools=24.8 gmx_mmpbsa mpi4py -y

Important caveats¶

  • MM-GBSA is approximate (implicit solvent, limited entropy; useful for comparing poses, not experimental Kd without calibration).
  • Short trajectories (e.g. <1–10 ns) give noisy averages — prefer ≥10–100 ns production MD before trusting numbers.
  • Optional per-residue decomposition (RUN_DECOMP = True) is much slower and is off by default (mean ΔG only).

Verdict (this 100.0 ns production run)¶

The mean ΔG estimate is favorable, but uncertainty or unbound frames weaken a retained-pose reading.

Question Answer from this run
Is estimated ΔG_bind favorable (negative)? Yes. Mean -39.80 kcal/mol (gmx_MMPBSA aggregate, GBSA).
Is that distinguishable from zero? Yes. Per-frame SEM 0.96 kcal/mol; bootstrap 95% CI [-41.83, -37.97] (entirely < 0).
Do frames flip to unbound (ΔG ≥ 0)? Yes. 54 of 1001 frames have ΔG ≥ 0.
Does that prove stable high-affinity binding? No. MM-GBSA is approximate and usually too favorable vs experiment; this is not a calibrated Kd.

Read this as: Some frames have ΔG ≥ 0 (54/1001). Do not treat this as a retained bound pose without inspecting those frames and Notebook 1 RMSD/contacts.

What would support stable binding more strongly¶

  • Production MD ≥10–100 ns with the same protocol, still negative ΔG and no late drift toward 0.
  • Notebook 1: ligand RMSD stays in the pocket and receptor contacts remain high over that longer window.
  • Optional: MM-PBSA and/or per-residue decomp (RUN_DECOMP = True) agreeing on a persistent interface.
  • Experiment (binding assay) if the scientific claim is biological affinity.

What would weaken or reject the hypothesis¶

  • Mean ΔG near 0 or positive, or a 95% CI that includes 0.
  • Per-frame ΔG trending upward (less favorable) or crossing to unbound in the second half of the run.
  • Large ligand RMSD / loss of pocket contacts in Notebook 1, even if early frames look favorable.

How to read the numbers (same protocol only)¶

  • Sign: more negative → more favorable estimated binding in this GB model.
  • Magnitude (-39.80 kcal/mol): typical MM-GBSA overbinding for a peptide-sized ligand; do not convert to experimental Kd.
  • Spread (SD ~30 kcal/mol, SEM ~1.0): frame-to-frame fluctuation is large; the mean is well determined on 1001 frames, but the physical uncertainty is larger than SEM (force field, GB model, missing entropy, truncated pocket).
  • Compare poses / mutants / run lengths only when force field, igb, salt, and frame selection match.

Sampling caveat¶

This trajectory is ~100.0 ns (1001 frames). Length is no longer the main limit; MM-GBSA is still approximate. Experiment is required for a strong affinity claim.
